# Fly By Night: versão Front-End

Versão inicial do site/projeto de exemplo apenas com HTML e CSS. 

As tabelas e os formulários estão sem dados de exemplo, com comentários indicando onde os dados dinâmicos serão inseridos. 

Os botões dos formulários são apenas elementos visuais: não há persistência, conexão com banco, SQL e JavaScript na aplicação.

O PHP permanece somente para reutilizar `componentes/cabecalho.php` e destacar a seção atual. Execute o servidor na raiz com:

```sh
php -S localhost:PORTA
```

A porta pode ser 80 ou qualquer outra que não esteja em uso.

Abra `http://localhost:PORTA` no navegador para visualizar o projeto.

**Atenção:** neste projeto, vamos seguir utilizando o banco de dados flybynight criado nas aulas anteriores. Mas caso você não tenha este banco, na pasta **dump** deixei um arquivo de backup (**flybynight_completo**) que você pode importar em seu phpMyAdmin.

# 🌽 Pamonha Caseira de Milho Verde

Uma receita tradicional, saborosa e perfeita para acompanhar um bom café.

* **Tempo de preparo:** 1 hora
* **Rendimento:** Depende do tamanho das espigas (aproximadamente 6 a 8 pamonhas)

---

## 🛒 Ingredientes

* **12 espigas** de milho verde (guarde as palhas para embalar)
* **1 copo** de água
* **2 xícaras** de açúcar
* **1 xícara** de coco ralado fino
* **1 pitada** de sal

---

## 🛠️ Utensílios Necessários

* Liquidificador
* Panela grande
* Escumadeira
* Espátula de silicone

---

## 👩‍🍳 Modo de Preparo

1. **Prepare o milho:** Rale as espigas ou corte os grãos rente ao sabugo. Bata o milho no liquidificador junto com o copo de água até virar uma massa homogênea.
2. **Tempere a massa:** Despeje a massa em um recipiente, acrescente o coco ralado, o açúcar, a pitada de sal e mexa muito bem.
3. **Modele as pamonhas:** Coloque porções da massa dentro das palhas de milho limpas e amarre-as muito bem (com barbante ou tiras da própria palha) para não vazarem.
4. **Ferva a água:** Em uma panela grande, coloque água para ferver. 
5. **Cozinhe:** Assim que a água estiver em **fervura completa**, coloque as pamonhas uma a uma. *Atenção: a água precisa estar realmente fervendo, caso contrário as pamonhas podem se desfazer.*
6. **Tempo de cozimento:** Deixe cozinhar por aproximadamente **40 minutos**. Retire-as da água com o auxílio de uma escumadeira.
7. **Esfrie e sirva:** Deixe as pamonhas esfriarem em um local bem fresco. Sirva morna ou fria acompanhada de café e queijo ralado.
